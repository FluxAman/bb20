# 🥊 BIGG BOSS FIGHT : TEKKEN 8 PRO EDITION

A photorealistic, browser-based fighting game built with Canvas, Vanilla JavaScript, and the Web Audio API. Inspired by the intense drama of Bigg Boss and the combat mechanics of Tekken 8.

---

## 🌟 Key Features

- **⚡ OP & 🎸 Rockstar Character Archetypes**:
  - **Baseer Ali ("Braid Hustler")**: Street kickboxing style, cyan lightning strikes, and rapid OP punches (*"OP BHAI OP!"*).
  - **Abhishek Malhan ("Zipper Boy")**: Heavy street brawler with Electric God Fist uppercuts and futuristic biker jacket (*"OP BOLTE!"*).
  - **Qazi Bohemian**: Capoeira acrobatics, sonic microphone waves, and rose-pink flowing robe (*"ROCKSTAR ENERGY!"*).
  - **Qazi Emotional**: Passionate counter-striker with gold sequin sherwani armor and crying diamond shockwaves (*"DIL SE ROCKSTAR!"*).

- **🗡️ Sword Weapon Combat System**:
  - Characters carry sheathed katanas on their backs.
  - Draw blade with metallic unsheathe chime (`Chiiing!`) and unleash luminous cutting motion trails.
  - Slicing hit impacts with heavy damage and **+20 HP Vampiric Life Transfer**.

- **✏️ Interactive Fighter Name & Title Customizer**:
  - Click directly on the Player 1 or CPU name badges to rename fighters in real time.
  - Custom names automatically update in the combat HUD, audio announcer, and victory evaluation screen.

- **🤖 AI Face & Suit Fitting Studio**:
  - Toggle between **AI Tekken 8 Suits** and **Classic Photos**.
  - Interactive sliders for Face Zoom / Scale and Vertical Alignment Offset for tailored neck and collar fitting.

- **🏟️ 3D Bigg Boss Eviction Arena**:
  - Central animated glowing Golden Bigg Boss Eye with rotating iris and pulse lighting.
  - Moving volumetric spotlights with atmospheric haze.
  - Polished dark glass floor with live inverted fighter reflections.

- **📱 Dual Responsive Controls**:
  - **PC Keyboard**: Full `WASD` movement, `Space` guard, `U/I/J/K/H/T/E/O` attacks.
  - **Mobile Touch Pad**: Ergonomic virtual 8-way D-Pad, dedicated Hold Guard, 4-Hit Combo, and 10-Hit Rage buttons.

## 🎮 Controls

| Action | PC Keyboard | Mobile Touch Pad |
|---|---|---|
| **Move Left / Right** | `A` / `D` | Virtual D-Pad Left / Right |
| **Jump** | `W` | Virtual D-Pad Up |
| **Crouch / Duck** | `S` | Virtual D-Pad Down |
| **Guard / Block** | `Space` | 🛡 HOLD GUARD |
| **Flash Jab (LP)** | `U` | `LP` Button |
| **Electric God Fist (RP)** | `I` | `RP` Button |
| **Low Sweep (LK)** | `J` | `LK` Button |
| **Tornado Kick (RK)** | `K` | `RK` Button |
| **Flying Dragon Kick** | `H` | `FLY` Button |
| **Bigg Boss Slam (Throw)** | `T` | `THROW` Button |
| **🗡️ Blade Slash (Sword)** | `E` | `🗡️ BLADE` Button |
| **🔥 10-Hit Rage Art** | `O` | `🔥 10-HIT RAGE` |

## 🚀 Live Deployment via GitHub Pages

1. In your GitHub repository, open **Settings** -> **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your game will be live in ~1 minute at:
   `https://fluxaman.github.io/bb20/`
